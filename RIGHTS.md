# Rights and attribution

No open-source licence has been selected for the team's original project materials or document-generation code. Repository visibility does not itself grant a licence.

Original supplied documents and institutional template elements retain their respective ownership. Third-party research is cited through source links, brief excerpts and labelled summaries. The research guide distinguishes source statements from proposed VerdictTrace extensions.

The team should agree on licensing for future code and datasets before a public release. Only data the team is entitled to redistribute should be included in a released dataset.
